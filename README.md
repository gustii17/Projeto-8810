## Objetivo 🎯
Desenvolver um módulo didático próprio e de baixo custo, capaz de reproduzir as principais funcionalidades do Datapool 8810, incluindo chaves, indicadores LED, protoboard, gerador de clock, ponta de prova e fontes de alimentação.

## Motivação 🚀
A disciplina de Eletrônica Digital é um componente fundamental na formação dos estudantes dos cursos de Engenharia que dependam de eletrônica. As atividades práticas na UFC (Universidade Federal do Ceará) são realizadas com o auxílio do módulo didático Datapool 8810, utilizado para a aplicação dos conceitos estudados em sala de aula. Entretanto, parte desses equipamentos apresenta desgaste e falhas de funcionamento, dificultando a realização dos experimentos. Além disso, os custos de manutenção ou substituição são elevados, evidenciando a necessidade de uma alternativa de baixo custo e de fácil manutenção.

## Projeto 🛠️
O projeto está dividido em basicamente 3 subprojetos, os quais são:
 - A PCB da Placa de Cima, resposável pela lógica e funcionamento geral do módulo, junto com o código do microcontrolador.
 - A PCB da Placa de Baixo, resposável pelo fornecimento de eneriga. _[Clique Aqui](/docs/POWER-BOARD.md) para mais informações_
 - O Modelo 3D do módulo.
